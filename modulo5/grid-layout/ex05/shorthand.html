Grid Layout

Itens: Shorthand -- grid-row e grid-column

Temos uma forma abreviada para declarar as propriedades de posicionamento, sendo elas grid-row para [grid-row-start e grid-row-end] e grid-column para [grid-column-start e grid-column-end] sendo que o primeiro valor passado sempre será o inicial e o segundo o final.

Item 1: [ grid-row: 2 / 5; ] - Valor horizontal: inicial 2, final 5 / [ grid-column: 3 / -1; ] - Valor vertical: inicial 3, final -1

Item 2: [ grid-row: 2 / 5; ] - Valor horizontal: inicial 2, final 5 / [ grid-column: 1 / 3; ] - Valor vertical: inicial 1, final 3

Item 3: [ grid-row: 1 / 2; ] - Valor horizontal: inicial 1, final 2 / [ grid-column: 1 / -1; ] - Valor vertical: inicial 1, final -1
