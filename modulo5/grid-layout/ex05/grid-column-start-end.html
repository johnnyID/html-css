Grid Layout

Itens: Alinhamento dos itens com base nas grid-lines no eixo vertical -- grid-column-start e grid-column-end

A propriedade grid-row-start/end tem como função posicionar os itens no container de forma precisa e com objetivo principal em ocupar uma área maior das grid-lines, ou seja, em um container 3x3 = 92 a possibilidade de itens que podem ocupar é de 9, porém 3 itens podem ocupar todo o espaço, e esse é o objetivo da propriedade, posicionar e ocupar uma área maior de cada item.

Exemplo: Um container com 3 itens ocupando um espaço preciso no eixo vertical

[ grid-column-start: 1; ] - Valor vertical inicial 1 / [ grid-column-end: 1; ] - Valor vertical final 1
[ grid-column-start: 1; ] - Valor vertical inicial 1 / [ grid-column-end: 1; ] - Valor vertical final 1
[ grid-column-start: 1; ] - Valor vertical inicial 1 / [ grid-column-end: 1; ] - Valor vertical final 1
