Grid Layout

Itens: Alinhamento dos itens com base nas grid-lines no eixo horizontal -- grid-row-start e grid-row-end

A propriedade grid-row-start/end tem como função posicionar os itens no container de forma precisa e com objetivo principal em ocupar uma área maior das grid-lines, ou seja, em um container 3x3 = 92 a possibilidade de itens que podem ocupar é de 9, porém 3 itens podem ocupar todo o espaço, e esse é o objetivo da propriedade, posicionar e ocupar uma área maior de cada item.

Exemplo: Um container com 3 itens ocupando um espaço preciso no eixo horizontal

Item 1: [ grid-row-start: 1; ] - Valor horizontal inicial 1 / [ grid-row-end: 3; ] - Valor horizontal final 3
Item 2: [ grid-row-start: 2; ] - Valor horizontal inicial 2 / [ grid-row-end: 4; ] - Valor horizontal final 4
Item 3: [ grid-row-start: 2; ] - Valor horizontal inicial 2 / [ grid-row-end: 3; ] - Valor horizontal final 3
