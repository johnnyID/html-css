Container: Espaçamento entre os itens -- gap

A propriedade gap é utilizada para gerar espaçamento entre os itens.

[ gap: 50px 20px; ] - Gera espaçamentos entres os itens na linha e na coluna, sendo o primeiro valor passado [50px] para linhas e o segundo valor [20px] para colunas. Podemos pôr apenas um valor para ter espaçamento igual para colunas e linhas.
