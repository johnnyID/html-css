Grid Layout

Container: Grid implícito -- grid-auto-rows e grid-auto-columns

Grid implícito é a adição de mais columns/rows no grid, no qual não declaramos suas características - largura/altura -, ou seja, se por algum acaso o back-end com sua lógica adicionar uma nova columns/row, as mesmas não terão a mesma características das antes declaradas, elas terão o valor padrão dela mesma, não possuindo o comportamento das demais. Para resolver este problema, temos duas propriedades que automatiza as características que serão atribuídas para todas as columns/rows adicionadas posteriormente, sendo elas: grid-auto-columns e grid-auto-rows.

Ambas propriedades - grid-auto-columns e grid-auto-rows - delimita suas características - largura ou altura - para columns/rows adicionadas posteriormente das demais, ou seja, podemos personalizar com as mesmas medidas das anteriores. O uso destas propriedades facilita na dinamicidade do código, pois não há necessidade de ir no CSS adicionar uma nova column/row nas propriedades grid-template-columns e grid-template-rows. Imagina como seria adicionar novas columns/rows manualmente quando necessário.

[ grid-auto-rows: 100px; ] - Toda linha/row adicionada posteriormente, terá sua altura determinada para 100px.
