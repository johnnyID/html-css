Container: Alinhamento dos Itens nos Eixos -- align-items

A propriedade align-items é utilizado para alinhar e organizar os itens dentro das linhas do container, sendo o align-items para o eixo transversal [cross-axis]. Vejamos exemplos.

[ align-items: stretch; ] - Os itens alinham-se à altura das linhas dentro do container, criando um efeito de esticar. Valor padrão.
