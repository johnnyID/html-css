Flexbox

Itens: Aumento de tamanho dos itens no eixo principal -- flex-grow

A propriedade flex-grow permite os itens aumentarem de tamanho para ocupar todo o espaço disponível da linha do container no eixo principal [main-axis]. O mesmo possui apenas dois valores, sendo eles: 0 para negar o aumento de tamanho e 1 para permitir o aumento de tamanho

[ flex-grow: 0; ] - Como valor padrão, flex-grow não permite o aumento de tamanho dos itens para ocupar todo o espaço disponível da linha do container no eixo principal [main-axis] de forma responsiva.

[ flex-grow: 1; ] - Com valor sendo 1, flex-grow permite o aumento de tamanho dos itens para ocupar todo o espaço disponível da linha do container no eixo principal [main-axis] de forma responsiva.

Podemos também, utilizar de forma individual, o flex-grow para cada item, podendo passar como valor [flex-grow: 1; /ou flex-grow: 2; /ou flex-grow: 3; /ou flex-grow: n; (n = n números)] cada valor é uma parte maior do espaço extra, ou seja, com um container com 600px de espaço extra, o valor do item que possui [flex-grow: 1;] pega 1/6 do espaço, o valor do item que possui [flex-grow: 2;] pega 2/6 do espaço, o valor que o item possui [flex-grow: 3;] pega 3/6 do espaço. Ao somarmos as frações, vemos que atinge o valor de 6/6, ou seja, o valor distribuídos entre cada fração, é justamente o valor total do container. Vejamos exemplo abaixo:

Exemplo: container com 600px de espaço extra com 3 itens, o primeiro item com [flex-grow: 0;], o segundo com [flex-grow: 1;] e o terceiro com [flex-grow: 2;].

Primeiro item - [flex-grow: 0;] não permite crescer, mas possui seu próprio valor
Segundo item - [flex-grow: 1;] permite crescer 1/3 do espaço extra = 200px
Terceiro item - [flex-grow: 2;] permite crescer 2/3 do espaço = 400px
Somados, eles aumentarão 3/3 do espaço extra, 600px.
