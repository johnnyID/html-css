Flexbox

Flexbox é uma forma de organizar os elementos contidos no container pai de forma fluida. Ao utilizar o display flex [ display: flex; ] no pai e flex auto [ flex: auto; ] no itens dentro do container pai, os mesmo se adaptarão de acordo com o posicionamento, largura, altura... O importante saber é que o display flex junto ao flex auto dos itens, os conteúdos se adaptam.
